## 1. 项目概述

### 1.1 公司背景

德川和裕霖系同一经营主体的两个对外业务主体，主要从事非标零散模具及零部件制造业务。公司特点如下：

**业务特性：**
- **非标制造为主**：所有产品均为非标定制，不存在标准化的批量生产
- **以产品（模具）为核心**：所有业务数据围绕产品展开，每套模具独立核算
- **独立编组机制**：每套模具的定价、设计、物料、生产均独立编组，互不关联
- **双品牌运营**：德川和裕霖作为两个独立品牌对外对接客户，内部运营管理一体化

**现有痛点：**
- 业务数据分散在各环节，缺乏统一管理平台
- 产品信息维护不规范，设计变更难以追溯
- 生产进度不透明，难以实时掌握各工序状态
- 成本核算依赖手工，准确性低且耗时
- 跨部门协作效率低，信息传递依赖人工

### 1.2 项目目标

**核心目标：**

| 目标 | 说明 |
|------|------|
| 全流程数字化 | 实现从客户询价到收款的全业务流程线上管理 |
| 业财一体化 | 打通业务与财务数据，实现收入、成本、利润实时核算 |
| 数据驱动决策 | 提供实时、多维度的经营数据报表，支撑管理决策 |
| 提升运营效率 | 减少人工操作和重复录入，降低错误率 |

**预期价值：**
- 设计、生产、业务信息实时共享，减少沟通成本
- 每套模具独立核算，成本利润一目了然
- 生产进度可视化，缩短交付周期
- 财务报表自动生成，提升财务效率

## 2. 业务需求

### 2.1 基础数据管理

#### 2.1.1 产品信息管理（核心）

**需求描述：**

产品（模具）是公司业务的核心载体，所有业务数据均以产品为单位进行组织和关联。每套模具作为独立项目进行管理，包含完整的产品信息、技术参数、商务信息、图纸资料等。

**产品编码规则：**

产品以模具编号作为唯一标识符，编码规则建议如下：

| 编码要素 | 格式 | 示例 | 说明 |
|----------|------|------|------|
| 公司前缀 | 2位 | DC/YL | DC=德川，YL=裕霖 |
| 年份 | 4位 | 2025 | 项目立项年份 |
| 序号 | 3位 | 001 | 年度内流水号 |
| 完整编码 | 8-10位 | DC2025001 | 公司前缀+年份+序号 |

**字段要求：**

| 字段名称 | 字段类型 | 是否必填 | 说明 |
|----------|----------|----------|------|

| 客户名称 | 关联 | 是 | 关联客户 |
| 客户模号 | 文本 | 否 | 客户方模具编号 |
| 公司主体 | 枚举 | 是 | 德川/裕霖（对外签约主体） |
| **技术参数** | | | |
| 穴数 | 数字 | 否 | 一模出几个产品 |

| 排模日期 | 日期 | 否 | 排入生产计划的日期 |
| **商务信息** | | | |

| 客户确认图 | 文件 | 否 | 客户确认后的图纸 |
| 备料图版本 | 文本 | 否 | 备料图版本号 |
| 正式图版本 | 文本 | 否 | 正式图版本号 |

**功能要求：**

1. **编码管理**
   - 模具编号全局唯一，自动校验
   - 支持按公司主体+年份自动生成编号
   - 支持模具编号查询和模糊搜索

2. **产品明细（产品配置清单）**
   - 支持多条明细，每条明细记录一个物料项
   - 明细可包含：品名、规格、单位、数量、单价、金额
   - 明细支持排序和序号自动生成
   - 明细金额自动汇总

3. **图纸管理**
   - 支持多种图纸文件上传（PDF、DWG等）
   - 图纸版本控制，记录版本变更历史
   - 图纸与产品关联，可在产品详情页查看
   - 支持图纸在线预览（需技术评估）

4. **状态管理**
   - 产品状态随业务流程自动更新
   - 支持状态变更记录（时间、操作用户）
   - 可按状态筛选查询产品

5. **关联追溯**
   - 产品关联报价单、销售订单、采购订单、送货单
   - 支持从任一单据追溯到关联产品
   - 支持产品全生命周期视图

**业务流程：**

```
客户询价 → 创建报价单 → 立项 → 创建产品档案（模具编号）→ 设计阶段 → 采购阶段 → 生产阶段 → 质检阶段 → 出货 → 收款 → 完成
```

**验收标准：**
- [ ] 模具编号唯一性校验
- [ ] 可按公司主体+年份自动生成编号
- [ ] 支持产品明细多条记录
- [ ] 支持图纸文件上传和版本管理
- [ ] 可追溯产品关联的所有单据
- [ ] 产品状态随业务流程自动更新

### 2.2 销售管理

#### 2.2.1 报价管理

**需求描述：**

接收客户询价后，向客户发送报价单，记录报价信息和客户反馈。报价单确认后转为销售订单并立项。

**业务流程：**

客户询价 → 创建报价单 → 内部审批 → 发送客户 → 客户确认/还价 → 确认成交 → 立项 → 创建产品档案

## 3. 双公司主体管理

### 3.1 业务模式

德川和裕霖作为两个独立的业务主体对外运营，但内部管理一体化：

| 维度 | 说明 |
|------|------|
| 对外 | 分别以德川、裕霖名义对接客户、签订合同、开票 |
| 对内 | 统一管理产品设计、生产、成本核算 |
| 财务 | 收入、成本统一核算，不做独立财务分离 |

### 3.2 业务规则

**客户对接规则：**
- 一个客户可同时与德川、裕霖发生业务
- 业务发生时选择对应的公司主体
- 客户信息可记录两个主体的交易历史

**产品管理规则：**
- 产品（模具）不区分公司主体
- 采购、生产、质检统一管理
- 成本归集到产品，不按公司分摊

**销售统计规则：**
- 销售报表按公司主体分别统计
- 支持德川销售汇总、裕霖销售汇总
- 支持合并汇总查看

**财务报表规则：**
- 收入、成本统一核算
- 应收应付可按公司主体分别管理
- 利润报表按产品维度，不按公司维度

## 5. 权限设计

### 5.1 角色定义

| 角色 | 权限说明 | 数据范围 |
|------|----------|----------|
| 系统管理员 | 系统配置、权限管理、数据备份 | 全部数据 |
| 业务员 | 客户管理、报价、销售跟踪、收款跟踪 | 本人业务数据 |
| 工程 | 图纸设计、图纸确认、物料清单 | 全部产品数据 |
| 采购员 | 采购订单、采购入库、付款管理 | 全部采购数据 |
| 仓管 | 入库、出库、库存查询、盘点 | 全部库存数据 |
| 质检 | 质检记录、试模报告管理 | 全部质检数据 |
| 生产主管 | 生产计划、任务分配、进度跟踪 | 全部生产数据 |
| 财务 | 应收应付、财务报表、成本核算 | 全部财务数据 |

### 5.2 特殊权限

- **产品查看权限**：所有角色均可查看全部产品信息
- **成本查看权限**：财务可查看成本数据，其他角色仅查看销售价格
- **利润查看权限**：管理层可查看产品利润报表

## 6. 附录

### 6.1 术语说明

| 术语 | 说明 |
|------|------|
| 模具编号 | 产品的唯一编码，如 DC2025001 |
| 备料图 | 用于物料采购准备的初步设计图 |
| 正式图 | 用于生产制造的最终设计图 |
| 三方确认 | 工程、生产、业务三方对图纸的确认 |
| 试模 | 产品生产完成后进行的模具测试 |
| 送货单 | 产品出货时提供的发货凭证 |
| 对账 | 与客户核对应收款项的过程 |

### 6.2 业务流程图

```
客户询价 → 报价单 → 销售订单 → 立项 → 创建产品档案
                                            ↓
客户对接参数 ← 工程 ← 备料图 → 正式图 → 三方确认 → 客户确认
                                            ↓
物料需求 → 采购计划 → 采购订单 → 采购入库 → 物料齐备
                                            ↓
生产计划 → 周计划 → 任务分配 → 生产执行 → 工序完成
                                            ↓
试模测试 → 试模报告 → 质量判定 → 出货 → 送货单
                                            ↓
对账确认 → 收款计划 → 收款 → 财务报表 → 成本核算
```
