# 德川/裕霖业务管理系统 - 程序流程图

> 说明：以下流程图使用Mermaid语法编写，可复制到支持Mermaid的工具中查看（如：https://mermaid.live/、Notion、VS Code等）

---

## 1. 整体业务流程图

```mermaid
flowchart TD
    A[客户询价] --> B[报价管理]
    B --> C{客户确认?}
    C -->|否| D[修改报价/跟进]
    D --> B
    C -->|是| E[销售订单 & 立项]
    E --> F[创建产品档案<br/>模具编号]
    
    F --> G[工程设计]
    G --> H[客户参数对接]
    H --> I[备料图制作]
    I --> J[正式图制作]
    J --> K{三方确认}
    
    K -->|工程确认| K1[✓]
    K -->|生产确认| K2[✓]
    K -->|业务确认| K3[✓]
    K1 & K2 & K3 --> L{客户确认?}
    L -->|否| G
    L -->|是| M[物料需求 & 采购计划]
    
    M --> N[采购订单]
    N --> O[采购入库]
    O --> P{物料齐备?}
    P -->|否| M
    P -->|是| Q[生产计划]
    
    Q --> R[周计划]
    R --> S[任务分配]
    S --> T[生产执行]
    T --> U{工序完成?}
    U -->|否| T
    U -->|是| V[质检]
    
    V --> W[试模报告]
    W --> X{质量判定}
    X -->|合格| Y[出货]
    X -->|返工| T
    X -->|报废| Z[结束]
    
    Y --> AA[送货单]
    AA --> AB[对账确认]
    AB --> AC[收款计划]
    AC --> AD[收款]
    AD --> AE[财务报表 & 成本核算]
    AE --> Z
```

flowchart TD

## 3. 图纸设计确认流程

```mermaid
flowchart TD
    A[立项] --> B[工程与客户对接参数]
    B --> C[收集需求信息]
    C --> D[制作备料图]
    
    D --> E[上传备料图文件]
    E --> F[生成物料清单]
    F --> G[备料图版本管理]
    G --> H{确认?}
    
    H -->|修改| D
    H -->|通过| I[制作正式图]
    
    I --> J[上传正式图文件]
    J --> K[正式图版本管理]
    K --> L{三方确认}
    
    subgraph 三方确认流程
    L --> M[工程确认]
    M --> N[生产确认]
    N --> O[业务确认]
    end
    
    O --> P{全部通过?}
    P -->|有异议| I
    P -->|通过| Q{客户确认}
    
    Q --> R[客户反馈意见]
    R --> S{确认通过?}
    S -->|否| I
    S -->|是| T[客户确认签字]
    T --> U[确认日期记录]
    U --> V[进入生产计划]
```

## 绘制工具推荐

### 在线工具
1. **Mermaid Live Editor** - https://mermaid.live/
   - 直接粘贴代码即可生成流程图
   - 支持导出PNG、SVG格式

2. **Draw.io (diagrams.net)** - https://draw.io
   - 图形化界面拖拽绘制
   - 支持导出多种格式

3. **ProcessOn** - https://www.processon.com/
   - 中文界面
   - 协作功能强

### VS Code 插件
- **Mermaid Markdown Syntax Highlighting** - 语法高亮
- **Markdown Preview Mermaid Support** - 预览效果

### 绘图技巧

```
1. 流程图元素规范：
   - 开始/结束：圆角矩形
   - 处理步骤：矩形
   - 判断/分支：菱形
   - 输入/输出：平行四边形
   - 连接线：箭头

2. 流程图布局原则：
   - 从上到下，从左到右
   - 主流程走主线，分支走两侧
   - 保持流程清晰，避免交叉

3. Mermaid常用符号：
   - flowchart TD: 从上到下流程图
   - flowchart LR: 从左到右流程图
   - subgraph: 子流程
   - -->: 连接线
   - {|}: 判断条件
```
